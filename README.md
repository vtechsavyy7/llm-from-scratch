# llm-from-scratch

## Setup

```
git clone https://github.com/vtechsavyy7/llm-from-scratch.git
```

The `uv` package manager is used to setup the environment. To install `uv`, run the following command:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

To setup the environment, run the following command:

```bash
uv sync
```
